# cryptoAlpha

Cross-asset crypto factor research and modeling workspace.

## Structure
- `configs/`: project configuration files
- `data/`: raw, processed, features, labels, cache
- `factor_lib/`: factor expression library and lifecycle folders
- `notebooks/`: EDA, factor research, model research, backtest analysis
- `src/`: project source code
- `outputs/`: figures, reports, backtests, model checkpoints
